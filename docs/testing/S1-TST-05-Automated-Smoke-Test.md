# Sprint 1 Automated Smoke Test: Login and Main Page

**Project:** Gerodias PT (Hope, Inc. ERP)  
**Task ID:** S1-TST-05  
**Prepared by:** Hazel Espiso  
**Role:** Test Engineer  
**Status:** Done

## 1. Objective

To verify that the login functionality and main page work correctly through automated smoke testing. The tests aim to identify major issues that may prevent users from accessing the system.

## 2. Testing Scope

- Login page accessibility
- Valid login credentials
- Invalid login credentials
- Successful login redirection
- Main dashboard/page loading
- Essential page elements
- Main page navigation
- Logout functionality, if applicable

## 3. Test Cases

| Test ID | Test Scenario | Expected Result |
|---|---|---|
| SMK-001 | Open login page | Login page loads successfully |
| SMK-002 | Login using valid credentials | User logs in successfully |
| SMK-003 | Login using invalid credentials | System displays an appropriate error |
| SMK-004 | Verify login redirection | User is redirected to the main page |
| SMK-005 | Load main dashboard | Dashboard loads without errors |
| SMK-006 | Verify essential page elements | Required elements are displayed |
| SMK-007 | Navigate through main page | Navigation works correctly |
| SMK-008 | Logout from the system | User session ends successfully |

## 4. Automation Requirements

- Use the existing project testing framework.
- Automate the login and main page smoke test scenarios.
- Verify expected page behavior and results.
- Record test failures and errors.
- Avoid modifying unrelated application functionality.
