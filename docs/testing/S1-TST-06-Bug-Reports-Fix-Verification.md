## 3. Bug Report Template

| Field | Description |
|---|---|
| Bug ID | Unique bug reference |
| Bug Title | Short description of the issue |
| Module | Affected system module |
| Severity | Critical, High, Medium, or Low |
| Priority | Urgency of the fix |
| Steps to Reproduce | Steps needed to trigger the issue |
| Expected Result | Correct system behavior |
| Actual Result | Observed system behavior |
| Evidence | Screenshot or error message |
| Status | Open, In Progress, Fixed, Retest, or Closed |
